# 빠른 배정과 상태 보관

[연동](INTEGRATION.md) · [요청 래퍼](APPLICATION-INTEGRATION.md) · [CSR](CSR.md)

`decide()`는 캐시된 정책과 서명 문맥으로 선택한다. 원격 호출을 기다리지 않지만 HMAC 검증 등 로컬 비동기 연산은 있다. 캐시는 사용자 상태를 보관하지 않으며 Service Binding별 isolate에서 공유한다. 기본 재확인 간격은 마지막 성공한 확인 후 15분이며 최대 나이는 원래 발행 후 6시간이다. 같은 정책을 확인하면 재확인 타이머만 갱신하고 발행·학습 시각은 유지한다. stale 정책은 사용하면서 갱신하고 cold/만료는 미참여 후 백그라운드 갱신한다.

서명 문맥이 없어도 정책이 유효하면 로컬에서 새로 배정할 수 있다. 문맥은 같은 기기에서 유지 기간·관측 표본을 이어가기 위해 저장한다. `decisions.secret`은 최소 32 UTF-8 바이트의 서버 secret이다. `tokens`에 이전 문맥을 제공하고, 변경된 문맥을 `onPrepared`로 서버 세션에 저장한다. 이 콜백은 새 배정·관측 시작 등 문맥 변경과 외부 문맥의 명시적 prepare 저장 시 호출된다. 같은 관측의 반복 노출은 사건만 수집하고 상태를 다시 저장하지 않는다. 응답 이후 헤더를 수정할 수는 없다.

쿠키만 사용할 때는 실제 노출 처리 후 `await eye.state()`로 로컬 서명을 기다린 뒤 응답에 쓴다. 이 API는 원격 I/O를 하지 않는다. onPrepared의 호스트 저장은 별도로 순서대로 백그라운드 실행하며 state()를 지연시키지 않는다. 쿠키 크기와 실험 개수는 호스트가 관리한다. [쿠키 예제](../examples/cookie-host.ts)는 하나의 실험을 보여준다. state 저장 실패는 서비스의 오류 경계에서 처리한다.

`prepare()`는 사용 가능한 정책 캐시를 재사용하고, 신선도 기간을 지난 캐시는 백그라운드 갱신한다. 캐시가 없거나 하드 만료되면 정책 RPC를 기다린다. `prepare({ subject, experimentId, forceRefresh: true })`는 캐시를 우회해 명시적으로 조회한다. 같은 캐시의 동시 일반 준비 요청은 진행 중인 조회를 공유하며, 강제 조회는 공유하지 않는다. 별도 준비 경로·관리 작업에서 사용하거나 서버 응답 지연을 허용할 때만 직접 기다린다. 반환한 `reuseUntil`은 해당 결정의 적용 기한이며 장기 문맥의 저장 기한이 아니다. 정책을 새로 받아도 같은 arm의 유지·관측 문맥은 계속 사용할 수 있다. 15분 토큰·중앙 예약·decideConsistent는 제공하지 않는다.

로그인·로그아웃·계정 변경에서는 해당 사건을 수집하고 이전 신원의 문맥을 비운다. 같은 uid의 기기 간 배정을 중앙에서 맞추지 않는다. 동시에 들어온 요청이나 저장 실패로 문맥이 갈라질 수 있으며 원장으로 복구하지 않는다. 장기 유지가 중요하면 호스트 세션의 항목 단위 갱신·동시 요청 정책도 함께 설계한다.

## 운영 목표와 측정

onDecision으로 참여/미참여를 지역·신규/재방문·인증 여부별로 측정한다. onError로 전송·상태 저장 실패를 집계하고 arm별 수신 품질을 대조한다. 작은 유실 허용은 무편향 보장이 아니다. 새 버전의 p95/p99·미참여율·비용은 실제 서비스에서 다시 측정해야 한다. 기존 v1 부하 수치는 현재 구조의 검증값이 아니다.

서버는 새 학습·설정 변경이 없으면 기본 한 시간 동안 발행을 재사용한다. 감쇠·탐색을 위해 이후 조회에서 재평가하며, 짧은 학습 반감기나 호스트의 더 짧은 maxAgeMs는 재평가 간격도 줄인다. 반영 지연에 민감한 실험은 freshMs와 maxAgeMs를 함께 줄인다. arm 중지의 즉시 반영이나 전역 캐시 무효화를 보장하지 않는다.

freshMs를 생략하고 짧은 maxAgeMs만 지정하면 자동 재확인 간격은 15분과 maxAgeMs 절반 중 작은 값(최소 1ms)을 사용한다. 두 값을 모두 지정할 때는 freshMs가 maxAgeMs 이하여야 한다. CSR refreshAfter도 같은 유효 간격을 사용한다.
